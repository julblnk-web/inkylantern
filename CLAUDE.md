# Inky Lantern Studio — portfolio site

The studio was renamed from Black Pixel Studios to Inky Lantern Studio on 2026-11-15; the site uses the new name everywhere, including copyright lines.

Website for Inky Lantern Studio, a themed environment design studio led by Julia Bilenko, founder and creative director: themed environment and experience design for small attractions and venues (FECs, immersive dining, themed bars, visitor attractions, themed park areas).

## Files
- `index.html` — the whole site, one page, plain HTML with inline styles. No build step: open it in a browser.
- `images/` — project images and `inky-lantern.png` (the logo, white on transparent background). `logo.png` is the old Black Pixel logo, no longer used.

## Brand (keep unless asked to change)
- Display font: Cormorant Garamond, weight 500 (Google Fonts). Body: Inter. (Changed from Instrument Serif + Archivo on 2026-11-15.)
- Colours ("deep forest + brass", changed from night ink + amber on 2026-11-16): forest ink #0F1614 (background), raised #18221F, parchment #ECE7D8 (text), soft text #C3CCC4, muted #8FA097, lines #2C3A35 / #4A5C55, brass #D4A24C (accent: buttons, markers, project subtitles only; button hover #E0B263).
- Signature element: project details shown as a drawing title block (ruled grid with the logo and "Drawn by Julia Bilenko").

## Positioning
- Present the site as the studio, led by Julia. Hero carries the line "Inky Lantern Studio is led by Julia Bilenko, founder and creative director."
- "We" for how the studio works today (concept and design led by Julia; illustrators, technical designers and fabricators brought in per project). "I" for Julia's own ten years of experience.
- Never claim permanent staff or a team size.
- Past projects stay credited to Julia personally, with her original role in each title block. Never describe them as studio work.

## Rules
- Keep all project facts, credits and copyright lines exactly as they are; they come from Julia's portfolio PDF.
- Avoid all-caps labels, eyebrow labels, and numbering things that aren't a sequence.
- Must work on phones, keep visible keyboard focus, keep text contrast at WCAG AA.
- Contact: an "Email us" button (mailto:julietbilnko@gmail.com; the address itself is not shown as text) and linkedin.com/in/julia-bilenko as an icon link. No phone number on the site (removed 2026-11-15).
